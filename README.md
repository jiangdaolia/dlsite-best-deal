# DL Price Tracker + DLsite 优惠助手

为 DLsite 补充史低、理论优惠价、购物车门槛、优惠券/平台活动筛选，以及多语言版本比较的用户脚本。

本项目直接基于 [syoius/dlTracker4TamperMonkey](https://github.com/syoius/dlTracker4TamperMonkey) 修改和扩展；该项目又基于 [Cassandra-fox/dlTracker](https://github.com/Cassandra-fox/dlTracker) 改写。史低和公开价格走势数据来自 [DLwatcher](https://dlwatcher.com/)。项目继续采用 MIT 许可证并保留原作者署名。

## 安装

**[安装 DLsite 优惠助手 + 史低](https://cdn.jsdelivr.net/gh/jiangdaolia/dlsite-best-deal@v0.6.98/userscript/dl-price-tracker.user.js)**

上面这条钉在当前版本 tag，点开拿到的一定是这一版（`@latest` 会命中 jsDelivr 的 tag 解析缓存，实测可能返回好几版之前的旧文件，所以装的时候不用它）。桌面端可使用 Tampermonkey、Violentmonkey 等用户脚本管理器；Via 等支持 `.user.js` 的手机浏览器可直接打开安装链接。

装完之后就不用再手动装了：脚本的更新地址是 GitHub 官方的**最新 release 附件永久地址**（`releases/latest/download/...`，内容永远指向最新一版），同时脚本自己每 6 小时问一次最新版本，真有新版时右下角会出现一条可关闭的小提示，点「去更新」即可——两条路都不依赖 `@latest` 的解析缓存。

打不开时的备用入口（任选其一）：

- jsDelivr 跟随最新 tag（可能滞后几版）：`https://cdn.jsdelivr.net/gh/jiangdaolia/dlsite-best-deal@latest/userscript/dl-price-tracker.user.js`
- raw 直连（少数网络可用）：`https://raw.githubusercontent.com/jiangdaolia/dlsite-best-deal/main/userscript/dl-price-tracker.user.js`
- raw 被墙时代理：`https://gh-proxy.com/https://raw.githubusercontent.com/jiangdaolia/dlsite-best-deal/main/userscript/dl-price-tracker.user.js`
- [Releases](https://github.com/jiangdaolia/dlsite-best-deal/releases) 里每个版本的 `dl-price-tracker.user.js` 附件

### 更新不到新版本怎么办

先看右下角有没有「有新版本 vX.Y.Z」的小提示：有就点「去更新」，那条链接钉死在那个版本上，一定能装到。没有提示但确定发了新版，再按下面排查：

1. 打开 `chrome-extension://dhdgffkkebhmkfjojejmpbldmpobfkfo/options.html#nav=utils`（Tampermonkey 设置 → 工具）或在脚本列表里点「检查更新」。
2. 看该脚本的「更新 URL」：应该是 `github.com/.../releases/latest/download/dl-price-tracker.user.js`。如果指向 `raw.githubusercontent.com`，或者指向**某个固定 tag**（`@v0.6.89`、`@v0.6.90` 这类），或者还是 `cdn.jsdelivr.net/...@latest`，说明装的是旧版——这几种地址都收不到（或收不全）新版本，用上面的安装链接重装一次即可就地升级。
3. 地址对了但仍提示「已是最新」或报网络错误：GitHub 的部分下载域在国内可能连不上，这种情况直接用 Releases 里的附件，或等脚本自己的提示。

日常使用只需安装主脚本 `userscript/dl-price-tracker.user.js`。`userscript/dlsite-coupon-reader.user.js` 是诊断工具，与主脚本同时启用会在购物车页产生重复读取和重复展示。

## 主要功能

- 在作品详情、搜索、分类、排行、活动、社团、收藏、购物车和推荐卡上显示史低、本次可到和价格趋势。
- 读取账号优惠券与平台活动，识别作品、社团、站点、类型、分类、价格、件数和金额条件；多件活动同时支持`N件X%OFF`和`3件999円`这类定额组合。
- 以“当前平台折扣或多件活动，再叠加一张优惠券”的规则计算理论最低价；定额活动按每部 999÷3=333 日元计理论价，余数部分按原价。每单最多使用一张券。
- 在购物车显示人民币/日元价格、平台折扣、史低、门槛差额和拼单候选，但不会自动移动作品、套券或下单。
- 浏览列表和“稍后再买”支持优惠力度、理论低价、平台折扣失效时间排序。
- `优惠券和平台活动`按钮可分别选择一种平台活动和一种优惠券；同时选择时按适用作品交集筛选，两项都不选时显示全部。
- 比较同一作品的不同语言版本，显示各版本理论最低价，并提醒已购买、已在购物车或稍后再买的同语言/其他语言版本。
- `账号信息`与购物车页的`读取账号信息`悬浮按钮可读取优惠券、购物车和已购清单，差分更新本地语言家族索引，并在读完后重算当前页优惠金额；账号数据只在点击时读取，页面不会自动发起账号请求。
- 已购买作品页在价格列表头提供`数量对不上？`：把本页（含翻页、沿用当前筛选）实际列出的作品与已购接口清单逐条做差集，直接列出页面少显示的编号。
- 已购买作品页在价格列表头提供`算算亏了多少`：点击后**先把购买历史展开到全部**（反复点原站的`もっと見る`直到点不出新行），再逐行在`价格（含税）`下显示`史低379 JPY / 16.16 RMB`，同时逐条对比实付与史低、算出比史低贵了多少、一共多花多少；差额与汇总金额都同时给出日元和人民币（`+1,076円 ≈ +¥45.84`），不用自己换算；不点则页面保持原样、不发请求。

## 使用要点

### 浏览与筛选

普通作品卡在 DLsite 原生标签区之后显示`本次`、`史低`、`趋势`和简洁优惠信息，不修改原生标题、封面、价格或操作区。手机端与窄卡会自动收缩或换行。

`优惠券和平台活动`按钮打开双选弹窗：

- 平台活动最多选一种，也可选`不选择平台活动`。
- 优惠券最多选一种，也可选`不选择优惠券`。
- 同时选择时，只显示两项都适用的作品。
- 两项都不选时恢复全部作品。
- 两类选项分别按显示的 OFF 从高到低排列。
- 优惠券选项按`力度·条件｜进度`紧凑格式显示；`优惠券`标签右侧的类别多选框（同人、漫画、游戏、手机游戏、AI生成、女性向等，与官网券列表筛选口径一致）可缩小券列表，默认勾同人和女性向，勾选状态会记住。固定满减券显示真实满减金额。

列表还可以独立隐藏已购买作品，以及理论价不低于购物车/稍后再买版本的作品。排序、筛选和隐藏状态会保存在浏览器本地。

### 购物车

购物车每部作品下方显示`本次`、`史低`、`平台`、状态和`价格趋势`。状态分为`需凑单`、`门槛已满足`和`单买即最优`。

优惠券和平台活动分别使用表格展示。优惠券默认显示前两种，其余可展开。拼单推荐只读展示候选和差额；“加购物车”只在用户点击后代理 DLsite 当前页面已有的单件操作。

### 语言版本与账号信息

购物车、稍后再买和详情页提供`比较语言版本`。比较表按语言列出作品编号、人民币/日元、现在/平台/史低、备注、详情和购物车操作。多个译者子商品必须由用户明确选择，脚本不会自动替换语言或批量操作。

`账号信息`中的读取按钮与购物车页悬浮按钮共用同一条流水线，有一分钟操作冷却。读取过程显示进度条并可以随时停止，中断的进度会保留并可在任意页面续接；遇到 403、429 或验证页会停止，不自动重试。

读取范围以`已购买作品`页为准：除了已购接口，还会同源读一次`已购买作品`页（含翻页），只针对页面上真正列出的作品读元数据；如果当前就在已购买页，会先把列表展开到全部再读。**已购买页的月份筛选写在地址路径里**（`/mypage/userbuy/=/year/2026/month/10/`），所以读取一律从未筛选的已购买页地址开始；页面切到`全部`后还要再点一次`表示`才生效，脚本会把这次提交算出来同源抓一遍，等于替你点了那次`表示`。万一还是只拿到一部分（页面条数明显少于接口），会自动退回接口全量并在面板写明原因——不会再把「只看 10 月」的 3 部当成全部。接口里多出来的跨分区、已下架、旧编号不计入`已购买`数量，面板上单列成`页面未列 N 条`——所以那里的数字和页面上看到的条数一致。页面读不到时自动退回接口全量。

## 价格与安全边界

- 人民币换算优先使用 DLsite 同一作品的结构化 CNY/JPY 价格；缺失时才回退到可靠购物车样本。
- `满1,200减400`在单作品理论标签中按约 33OFF 表示，购物车结算计算则按每单精确减 400 日元。
- 平台活动页同一 `bulkbuy_key` 24 小时内最多读取一次（含已结束页）；结构无法识别时 10 分钟内不重试。作品元数据和理论价使用本地缓存。
- 公开作品信息请求不携带登录 Cookie；购物车、已购清单和优惠券只在识别当前账号时使用登录态。
- 脚本不会自动购买、自动换语言、自动套券、批量加购或访问第三方翻译/AI 服务。
- 所有价格与方案仅供参考，以 DLsite 实际结算为准；低频请求也无法承诺零风控风险。
