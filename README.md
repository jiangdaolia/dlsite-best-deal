# DL Price Tracker + DLsite 优惠助手

为 DLsite 补充史低、理论优惠价、购物车门槛、优惠券/平台活动筛选，以及多语言版本比较的用户脚本。

本项目直接基于 [syoius/dlTracker4TamperMonkey](https://github.com/syoius/dlTracker4TamperMonkey) 修改和扩展；该项目又基于 [Cassandra-fox/dlTracker](https://github.com/Cassandra-fox/dlTracker) 改写。史低和公开价格走势数据来自 [DLwatcher](https://dlwatcher.com/)。项目继续采用 MIT 许可证并保留原作者署名。

## 安装

**[安装 DLsite 优惠助手 + 史低](https://raw.githubusercontent.com/jiangdaolia/dlsite-best-deal/4132a1ecffdd89bb5e609b04c9b452f289c54f83/userscript/dl-price-tracker.user.js)**

桌面端可使用 Tampermonkey、Violentmonkey 等用户脚本管理器；Via 等支持 `.user.js` 的手机浏览器可直接打开安装链接。脚本包含 `@updateURL` 与 `@downloadURL`，实际更新行为由脚本管理器决定。

日常使用只需安装主脚本 `userscript/dl-price-tracker.user.js`。`userscript/dlsite-coupon-reader.user.js` 是诊断工具，与主脚本同时启用会在购物车页产生重复读取和重复展示。

## 主要功能

- 在作品详情、搜索、分类、排行、活动、社团、收藏、购物车和推荐卡上显示史低、本次可到和价格趋势。
- 读取账号优惠券与平台活动，识别作品、社团、站点、类型、分类、价格、件数和金额条件。
- 以“当前平台折扣或多件活动，再叠加一张优惠券”的规则计算理论最低价；每单最多使用一张券。
- 在购物车显示人民币/日元价格、平台折扣、史低、门槛差额和拼单候选，但不会自动移动作品、套券或下单。
- 浏览列表和“稍后再买”支持优惠力度、理论低价、平台折扣失效时间排序。
- `优惠券和平台活动`按钮可分别选择一种平台活动和一种优惠券；同时选择时按适用作品交集筛选，两项都不选时显示全部。
- 比较同一作品的不同语言版本，显示各版本理论最低价，并提醒已购买、已在购物车或稍后再买的同语言/其他语言版本。
- `账号信息`可读取购物车和已购清单，建立本地语言家族索引；普通页面不会定时轮询账号数据。

## 使用要点

### 浏览与筛选

普通作品卡在 DLsite 原生标签区之后显示`本次可到`、`史低`、`趋势`和简洁优惠信息，不修改原生标题、封面、价格或操作区。手机端与窄卡会自动收缩或换行。

`优惠券和平台活动`按钮打开双选弹窗：

- 平台活动最多选一种，也可选`不选择平台活动`。
- 优惠券最多选一种，也可选`不选择优惠券`。
- 同时选择时，只显示两项都适用的作品。
- 两项都不选时恢复全部作品。
- 两类选项分别按显示的 OFF 从高到低排列。

列表还可以独立隐藏已购买作品，以及理论价不低于购物车/稍后再买版本的作品。排序、筛选和隐藏状态会保存在浏览器本地。

### 购物车

购物车每部作品下方显示`本次可到`、`史低折扣`、`平台折扣`、状态和`价格趋势`。状态分为`需凑单`、`门槛已满足`和`单买即最优`。

优惠券和平台活动分别使用表格展示。优惠券默认显示前两种，其余可展开。拼单推荐只读展示候选和差额；“加购物车”只在用户点击后代理 DLsite 当前页面已有的单件操作。

### 语言版本与账号信息

购物车、稍后再买和详情页提供`比较语言版本`。比较表按语言列出作品编号、人民币/日元、现在/平台/史低、备注、详情和购物车操作。多个译者子商品必须由用户明确选择，脚本不会自动替换语言或批量操作。

`账号信息`中的`读取购物车和已购清单（请勿频繁读取）`有一分钟操作冷却。语言索引按批次串行读取，可续接中断进度；遇到 403、429 或验证页会停止，不自动重试。

## 价格与安全边界

- 人民币换算优先使用 DLsite 同一作品的结构化 CNY/JPY 价格；缺失时才回退到可靠购物车样本。
- `满1,200减400`在单作品理论标签中按约 33OFF 表示，购物车结算计算则按每单精确减 400 日元。
- 平台活动页同一 `bulkbuy_key` 24 小时内最多读取一次；作品元数据和理论价使用本地缓存。
- 公开作品信息请求不携带登录 Cookie；购物车、已购清单和优惠券只在识别当前账号时使用登录态。
- 脚本不会自动购买、自动换语言、自动套券、批量加购或访问第三方翻译/AI 服务。
- 所有价格与方案仅供参考，以 DLsite 实际结算为准；低频请求也无法承诺零风控风险。
