# DL Price Tracker + DLsite 优惠助手

## 项目来源

本项目直接基于 [syoius/dlTracker4TamperMonkey](https://github.com/syoius/dlTracker4TamperMonkey) 修改和扩展；该项目又基于 [Cassandra-fox/dlTracker](https://github.com/Cassandra-fox/dlTracker) 改写。因此，`syoius/dlTracker4TamperMonkey` 是本项目的直接上游，`Cassandra-fox/dlTracker` 是间接上游。

本项目继续遵循 MIT 许可证，并保留原作者署名。史低和公开价格走势数据来自 [DLwatcher](https://dlwatcher.com/)。

## 功能概览

- 在 DLsite 的作品详情、搜索、分类、排行、活动、社团、收藏和购物车等页面显示当前日元价、史低和价格走势入口。
- 自动读取平台活动和账号优惠券，显示适用折扣、件数/金额门槛、可用次数和中国时间到期时刻。
- 计算每部作品的“本次可到”理论价，点击可查看计算路径、购物车总价、门槛差额、拆单方案和拼单推荐。
- 计算弹框优先显示日元；当前作品有可靠的 DLsite 结构化 CNY/JPY 现价时优先按这一对价格估算人民币，缺失时才回退到购物车的可靠价格样本。
- 浏览列表和“稍后再买”支持“最高可达到折扣”与“理论低价优先”排序，并可按需要凑件的具体活动或优惠券筛选。
- 列表原本未显示声优时自动补全；不依赖其他作品就能取得理论最优价时显示 `单买即最优`。

脚本包含标准 userscript 元数据以及 `@updateURL` 和 `@downloadURL`。安装页和更新检查的具体行为由浏览器或用户脚本管理器决定。

## 功能详情

### 价格、史低与本次可到

- 支持 DLsite RJ（同人）/BJ（乙女）作品页、收藏页、购物车和常见作品浏览列表。
- 中文等本地化价格后补充精确的当前日元价，并保留上游的史低标签和“查看价格趋势”链接。
- `本次可到` 以原价为基准：当前平台折扣与多件活动取更便宜的一项，再与一张最优适用券按规则叠加。例如 `60% OFF` 后再用 `50% OFF` 券，综合为 `80OFF`。
- 本次可到价不高于史低时使用金黄色，高于史低时使用蓝灰色。
- `满1,200减400` 在单作品标签、排序和未凑齐作品的理论总价中按约 `33OFF` 表示；当前可结算价和拆单则按每笔订单满1,200日元精确减400日元。

### 计算弹框、购物车与拆单

点击详情、购物车或浏览列表中的“本次可到”后，弹框会显示：

- 当前作品最终入选的平台折扣/多件活动和优惠券计算路径。
- 购物车当前平台价合计、当前可结算最低价、理论最低价，以及两者的差额。
- 当前作品真正适用、但尚未满足的件数或金额门槛；不会混入其他作品专属优惠。理论价不会虚构未知凑单作品的价格。
- 只有确实比单笔结算更省时才显示的自动拆单方案。
- 从“稍后再买”按当前作品的最高券和平台活动给出拼单推荐。候选必须当前平台价不高于史低；缺少史低、超出目标券范围，或存在券层等效 OFF 更高的适用券时不会进入该券的候选。平台活动候选不受“更高券”排除规则影响。
- 满件数券和平台活动列出全部合格候选，不默认选择或计入总价；按综合 OFF、结算价和原顺序排列，默认显示前 10 部并可展开全部。同时需要活动与券时，每部候选都必须命中两者。
- 满额券先最小化超出门槛的金额；超额相同时优先更多作品，再比较实际结算总价、综合 OFF 和原顺序。每张并列最高券默认显示 1 个方案，可展开另外 2 个备选。方案总计中的“优惠前”采用平台折扣或平台活动后的价格合计，“优惠后”再扣除本单优惠券。
- 推荐表固定显示作品、人民币（日元）结算价、现在/平台/史低折扣、本单适用券、本单适用平台活动和等价最优路径备注。“现在折扣”按最终结算价相对原价计算；六列会随弹窗宽度自适应，人民币与日元分行，三种折扣合并为斜杠格式并高亮力度最大的一项。

每笔订单最多使用一张优惠券。最多对 12 部“立即购买”作品和 8 种相关券执行精确拆单；超出规模时仍显示单笔价格和门槛，但不输出近似拆单。

弹框的详细注意事项默认折叠；打开后背景页面停止滚动，只允许弹框内容滚动。弹框在后台完成计算后一次性更新，数据未变时不重复渲染，避免频繁闪烁。点击弹框外部、关闭按钮或按 `Esc` 可关闭。所有方案都只读展示，不会自动移动作品、套用优惠券或提交订单。

### 优惠券与平台活动

- 支持指定作品、社团、站点、作品类型和隐藏分类等结构化适用条件。
- 支持百分比券、固定减免券、满减券、一次性券和期限内可重复使用券。
- 同业务规则的多张券合并显示，但保留实例数量、使用次数和最早到期时间。
- 当前平台折扣与多件活动二选一；优惠券可与其中一项按规则叠加，优惠券之间不叠加。
- 多件活动优先使用结构化结束时间。日本时间 9 月 3 日 13:59 会显示为中国时间 9 月 3 日 12:59；如果只取得日期而没有时分，不自行虚构 `23:59`。

### 浏览列表排序、筛选与声优

脚本不修改 DLsite 原生排序下拉框，而是增加独立的“优惠助手排序”：

- `保持 DLsite 当前顺序`：恢复当前页面的原始顺序。
- `最高可达到折扣`：按理论最大 OFF 降序。
- `理论低价优先`：按“本次可到”理论日元价升序。

后两种排序在主字段相同时，都优先显示当前平台价不高于史低的作品；再相同时保持 DLsite 原顺序。“稍后再买”保留排序总开关，开启后只提供后两种排序。

排序控件在异步补全价格和优惠数据时保持原节点，不会反复重建或移动；macOS Chrome 展开原生下拉菜单后可以正常停留并选择。

“凑单优惠”筛选包含全部作品、所有需要凑件的优惠，以及每个具体的多件活动或件数券；选项中同时显示购物车件数进度。“稍后再买”使用同一套筛选选项和已选状态，并可与两种排序同时生效。纯金额门槛券不进入该筛选。

在手机版作品页中，排序与“凑单优惠”控件固定显示在主“作品一览”上方，不会误挂到页顶热门排行区。控件会先显示，具体活动和优惠券选项在异步数据读取完成后补全。

如果当前列表卡片未显示声优，脚本会从当页批量作品数据中补全全部声优，不为每部作品单独打开详情页。分页、无限滚动或 SPA 追加新作品后，会重新应用声优补全、筛选和排序。

### 购物车门槛与动态更新

- 只有“立即购买”作品参与满减金额、件数券和多件活动门槛。
- “稍后再买”作品仍显示自身的“本次可到”和适用优惠，但不增加当前金额或件数，仅用于排序和拼单推荐。购物车页会同时扫描“立即购买”和“稍后再买”，不套用普通浏览页的主列表限域。
- 满额券的拼单推荐只从当前已达或低于史低、符合目标券范围且没有更高券层优惠的作品中选择；先减少超额，同超额时优先更多合格作品。每张券最多保留 3 个方案。
- 快照分别保存“立即购买”和“稍后再买”。作品新增、删除或在两个区域之间移动后，脚本会重算价格、门槛、拆单、推荐和排序。
- 在其他页面打开计算弹框时使用最近的购物车快照，并显示更新时间与可能过期的提示；不定时轮询购物车。

## 自动读取、缓存与安全

- 优惠券缓存区分“从未读取”和“已成功读取 0 张”。只有无缓存、已知优惠券到期、成功购买、账号变化或主动打开“我的优惠券”页时才刷新，不定时轮询。
- 作品元数据缓存 30 分钟，每批最多读取 100 个尚未缓存的作品编号。只有当页无限滚动或 SPA 载入新作品时才读取后续批次，不预取其他分页。
- 脚本直接使用优惠券接口返回的结构化条件，不打开券详情，不翻动数千部适用作品的分页，不逐作品访问详情页。
- 多件活动只按作品的 `bulkbuy_key` 读取和缓存规则，不枚举整个活动的作品列表。
- 遇到 HTTP 403、429、验证码或异常 HTML 时，立即停止当页后续 DLsite 自动请求，不自动重试。
- 脚本对 DLsite 只执行同源只读 GET；不会自动加购、套券、下单，也不访问第三方翻译或 AI 服务。无法承诺零风控风险，实际结算仍以 DLsite 为准。

## 独立优惠券读取器（诊断用）

**[安装优惠券读取器 B 版](https://raw.githubusercontent.com/jiangdaolia/dlsite-best-deal/main/userscript/dlsite-coupon-reader.user.js)**

`userscript/dlsite-coupon-reader.user.js` 是诊断/验证工具，不是日常使用的主入口。它会在“我的优惠券”页面读取和诊断当前账号的优惠券，并在购物车页读取必要的批量作品条件。它不请求 DLwatcher，不打开优惠券详情，不翻适用作品列表。

诊断 JSON 会移除 Cookie、认证请求头、登录凭据、优惠券兑换码、邮箱和账号身份字段，但会保留真实优惠券 ID，因此不要公开上传诊断文件。主脚本和读取器同时启用时会在购物车页产生重叠读取与展示；日常使用建议只启用主脚本。
